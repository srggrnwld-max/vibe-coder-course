# VPa02 — первый Python-запрос

## Что это

Это учебный проект: скрипт на Python делает HTTP GET-запрос к `https://example.com` через библиотеку Requests и выводит статус-код и адрес запроса.

## Как запустить

Выполняйте команды из корня репозитория.

1. Убедитесь, что для проекта выбран Python 3.12. Если команда `python --version` показывает другую версию, при создании окружения укажите полный путь к установленному Python 3.12.
2. Создайте виртуальное окружение: `python -m venv venv`.
3. Активируйте его в PowerShell: `.\venv\Scripts\Activate.ps1`.
4. Установите зависимости: `python -m pip install -r "Модуль 1/VPa02/requirements.txt"` (то же, что `pip install -r "Модуль 1/VPa02/requirements.txt"`).
5. Запустите скрипт: `python "Модуль 1/VPa02/main.py"`.

## Как проверить

Скрипт должен выполниться без ошибки и вывести адрес `https://example.com/` и статус-код `200`.
