# VPa03 — Git и GitHub

## Что изучили

- разницу между Git и GitHub;
- `git init`;
- `git status`;
- `git add`;
- `git commit`;
- `git log`;
- `git remote`;
- `git push`;
- назначение `.gitignore`;
- работу с историей коммитов.

## Практика

В рамках урока существующий проект VPa02 был превращён в Git-репозиторий и опубликован на GitHub.

Были сделаны несколько осмысленных коммитов и настроена связь локального проекта с удалённым репозиторием.

## Главное, что понял

- `Ctrl+S` сохраняет файл;
- `git add` подготавливает изменения к коммиту;
- `git commit` фиксирует состояние проекта в локальной истории;
- `git push` отправляет коммиты на GitHub;
- Git и GitHub — разные вещи.
