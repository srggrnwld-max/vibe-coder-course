# Учебный менеджер паролей

CLI-приложение создаёт тестовые пароли, шифрует их через Fernet и хранит записи в локальной SQLite-базе.

Запуск из корня репозитория:

```powershell
.\venv\Scripts\python.exe ".\Модуль 1\VPa05\password-manager\password_manager.py"
```

Используйте только вымышленные логины и тестовые пароли. Файлы `passwords.db` и `vault.key` нельзя публиковать в Git.
