# VPa06 — PDF-чек-мейкер

Учебный скрипт на Python 3.12 читает заказы из CSV, собирает HTML-чек по шаблону и сохраняет отдельный PDF для каждого заказа.

## Что делает программа

1. Читает строки из `data/orders.csv`.
2. Группирует их по `order_id` и считает сумму заказа.
3. Подставляет заказ в шаблон `templates/check.html` через Jinja2.
4. Сохраняет PDF в `output/check-<order_id>.pdf` через WeasyPrint.

Один заказ может занимать несколько строк CSV: каждая строка — отдельная позиция чека.

## Как запустить

Команды выполняйте из корня репозитория.

1. Создайте окружение Python 3.12, если его ещё нет: `py -3.12 -m venv venv`.
2. Установите зависимости: `.\venv\Scripts\python.exe -m pip install -r "Модуль 1/VPa06/pdf-check-maker/requirements.txt"`.
3. Запустите скрипт: `.\venv\Scripts\python.exe "Модуль 1/VPa06/pdf-check-maker/main.py"`.

WeasyPrint на Windows может потребовать дополнительные системные библиотеки. Если установка или запуск завершатся ошибкой, сначала проверьте сообщение интерпретатора.

## Как проверить

В папке `output` должны появиться три файла: `check-1001.pdf`, `check-1002.pdf` и `check-1003.pdf`. В чеке `1001` итог `390.00`, в `1002` — `770.00`, в `1003` — `240.00`.

## Использованный промпт

Создай в папке `Модуль 1/VPa06/pdf-check-maker` учебный CLI-проект на Python 3.12. Скрипт должен читать заказы из CSV, группировать строки по `order_id`, подставлять данные в HTML-шаблон через Jinja2, создавать PDF через WeasyPrint, сохранять файлы в `output` и автоматически открывать готовые PDF. Не изменяй файлы за пределами папки VPa06.

## Оффер услуги

Создам для вашего бизнеса автоматический генератор PDF-чеков из CSV-выгрузки. Скрипт подставит товары, цены, количество и данные клиента в готовый шаблон и сохранит документы в отдельной папке. Услуга полезна интернет-магазинам, небольшим компаниям и специалистам, которые регулярно формируют однотипные чеки или счета. Вы получите удобный инструмент, который экономит время и снижает количество ручных ошибок.
